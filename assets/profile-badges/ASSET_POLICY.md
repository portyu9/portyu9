# Profile asset policy

My profile hero is intentionally stored at `quality-engineering-automation-systems.png` with the exact reviewed bytes.

- Size: `2,947,658` bytes
- SHA-256: `f99901f3da31c68441d471a92dcf9c7829681c8ec390286159b78eea97a5bcd0`
- Git blob: `97ea621c3c0de270a890fcb74e20bea9286e7d77`

The earlier UUID-style filename was removed without recompression; the Git blob is reused byte-for-byte. Lossless optimization was evaluated as a separate concern and deliberately not combined with the rename because changing the binary would invalidate the reviewed-byte contract and require a fresh visual-regression approval. Any future optimization should be performed as an isolated change with before/after pixel verification and a new pinned checksum.

Retired v1 nameplate and pre-responsive table-header assets are not part of my active profile contract and must remain absent.
